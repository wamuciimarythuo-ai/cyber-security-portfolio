# Metasploitable 2 Security Assessment Lab
## Overview
A hands-on security assessment of the intentionally vulnerable Metasploitable 2 virtual Machine using Kali Linux in an isolated virtual lab

The lab focuses on network reconnaissance, service enumeration, vulnerability investigation,, authentication testing and documenting security findings with appropriate remediation recommnendations.

## Objectives
-Perform network reconnaissance and service enumeration
-Investigate vulnerabilities and insecure service configurations
-Test authentication weaknesses in the authorizes lab.
-Document findings, security impact and remediation recommnedations

## Lab Environment
Attacker: Kali Linux
Target : Oracle VirtualBox
Tools : Nmap, Metasploit Framework, Searchsploit and Netcat

## Assessment Areas
-FTP backdoor
-SSH and Telnet authentication testing
-SMTP user enumeration
-HTTP/PHP-CGI vulnerability assessment
-Samba and Rlogin security testing
-Java RMI and bindshell investigation
-MySQL and PostgreSQL securitytesting
-VNC and UnreallRCD investigation

## Documentation
The accompanying report documents the objectives, procedures, commands, findings, security analysis and remediation recommendations for the assessment.
Screenshots are included in the report to support the investigation and demonstrate relevant results.

## Ethical Scope 
Testing was conducted against an intentionally vulnerable virtual machine in an isolated, authorized training environment. The activities were focused on understanding security weaknesses and learning appropriate defensive measures.

## Key Learning Outcomes
This lab provided practical experience in:
-Network reconnaissance and service enumeration
-Identifying potentially vulnerable services and insecure configurations
-Investigating authentication weakness in a controlled environment.
-Using security tools to examine exposed services.
-Analyzing potential security impacts
-Developing remediation recommendations and documenting assessment results.
